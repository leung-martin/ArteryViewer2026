# Facial Artery Viewer

An interactive 3D visualization of facial arteries overlaid on a translucent human head mesh. Built for anatomical reference and education.

**[▶ Open Viewer](https://leung-martin.github.io/ArteryViewer2026/)**

---

## Features

- **3 annotated arteries** rendered as 3D tubes over the face:
  - Dorsal Nasal Arteries
  - Lateral Nasal Artery
  - Superior Labial Artery
- **Click any artery** to select it and open a parameter panel
- **Adjustable parameters** per artery (length, diameter, Z position) with anatomical reference values drawn from published measurements
- **Orbit, zoom, and pan** with mouse or touch (OrbitControls with damping)
- **Reset View** snaps the camera back to its initial position

---

## Built With

- [Three.js r128](https://threejs.org/) — 3D rendering
- Vanilla JavaScript — no build step required
